# 04 Glosario

| Término | Definición | Fuente |
| --- | --- | --- |
| Estadística descriptiva | Resume y presenta datos mediante tablas, gráficas o números. | Semana 1, p. 11 |
| Inferencia estadística | Usa datos de una muestra para estimar o probar hipótesis sobre una población. | Semana 1, p. 11 |
| Parámetro | Medida de una población. | Semana 1, p. 11 |
| Estadístico | Medida de una muestra. | Semana 1, p. 11 |
| Frecuencia absoluta | Número de veces que aparece un dato o categoría. | Semana 1, p. 24 |
| Frecuencia relativa | Cociente entre la frecuencia y el número total de datos. | Semana 1, p. 24 |
| Coropleta | Mapa temático cuyas áreas sombreada representan valores de una variable. | Semana 1, p. 49 |
