01 · El mapa mínimo

Una pregunta se vuelve estudiable cuando defines sus piezas.

No memorices una lista aislada: identifica qué se observa, a quiénes, y qué medida describe cada grupo.

Describir

Hacer legibles los datos

La estadística descriptiva resume datos mediante tablas, gráficos o números para presentarlos de una forma fácil de comprender.

Inferir

Razonar desde una muestra

La inferencia usa datos de una muestra para estimar o probar hipótesis acerca de características de una población.

Población

El total de interés

Conjunto de todos los elementos del estudio. Una medida de población se llama parámetro.

Muestra

Una parte de ese total

Subconjunto de la población. Una medida de muestra se llama estadístico.

Observación

Una fila del estudio

Conjunto de mediciones obtenido para un elemento particular; no es lo mismo que la variable medida.

Regla de oro. Primero nombra la unidad estadística (el elemento observado); después, la población o muestra; al final, la variable y su escala. Ese orden reduce errores de clasificación.

02 · Clasifica con intención

El tipo de variable determina qué resumen y qué gráfico tienen sentido.

Responde con la escala más específica que puedas justificar con los datos disponibles.

Categóricas

Etiquetas, con o sin orden

Nominal: etiquetas que identifican un atributo. Ordinal: las categorías tienen un orden significativo.

Cuantitativas

Números que miden o cuentan

Discreta: conteos. Continua: mediciones. Las escalas de intervalo y razón usan unidades fijas; razón además tiene un cero significativo.

Corte transversal

Datos de varios elementos en el mismo momento.

Serie de tiempo

Datos recogidos a lo largo de varios períodos.

Panel

El mismo conjunto de elementos observado a lo largo del tiempo.

Clasificación rápida

No te fijes solo en que “parece un número”.

La satisfacción de huéspedes se registra como: 1 = muy insatisfecho, 2 = insatisfecho, 3 = satisfecho, 4 = muy satisfecho. ¿Qué escala es?

03 · De datos crudos a tabla

Frecuencia no significa solo “contar”.

Una tabla conserva el total y revela el peso de cada categoría. Después, elige una gráfica que mantenga esa lectura.

Caso fuente · 25 estudiantes

Color de camisa

rosa · azul · blanco · azul · rosa · gris · blanco · café · negro · blanco · rosa · azul · café · blanco · blanco · gris · azul · blanco · rosa · gris · gris · blanco · café · negro · verde

Cómo leer la tabla

  1. Ordena las categorías según un criterio explícito.
  2. Cuenta cada categoría: esa es la frecuencia absoluta f.
  3. Divide cada frecuencia por el total n: esa es la frecuencia relativa fr = f / n.

La categoría blanco es la más frecuente: 7 de 25 estudiantes (28%).

Decisión de representación

¿Qué usarías?

Para categorías como color de camisa, la presentación recomienda gráfico circular o de barras. Para una variable cuantitativa agrupada se emplean, entre otros, histograma, polígono u ojiva.

fr = f / n   ·   f acumulada(a) = observaciones ≤ a

La frecuencia acumulada corresponde a variables cuantitativas, porque requiere ordenar valores numéricos.

04 · Práctica integrada

Ahora tú construyes la distribución.

Usa el mismo método de clase, pero desarrolla la tabla completa antes de consultar la propuesta de solución.

Caso fuente · 15 clientes en un mercado

Gasto en US$

16.1 · 7.2 · 10.2 · 14.1 · 6.2 · 19.1 · 7.5 · 12.0 · 10.2 · 5.9 · 17.7 · 13.7 · 23.2 · 9.8 · 5.5

  1. Define n, mínimo, máximo y rango.
  2. Aplica Sturges: K = 1 + 3.3 log(n)Redondea K al entero inmediato siguiente.
  3. Calcula un ancho aproximado: ancho = (Xmax − Xmin) / KConstruye clases mutuamente excluyentes y colectivamente exhaustivas.
  4. Completa clases, punto medio, frecuencia absoluta, relativa y acumulada; finalmente diseña histograma, polígono y ojiva.
Ver una propuesta de resolución pedagógica

Dato fuente: n = 15, mínimo = 5.5 y máximo = 23.2; por tanto el rango es 17.7. Aplicación: K = 1 + 3.3 log(15) ≈ 4.88, por lo que se usan 5 clases. Un ancho práctico es 4 (17.7 / 4.88 ≈ 3.63, redondeado).
