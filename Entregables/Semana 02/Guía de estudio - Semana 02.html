Tendencia central · práctica activa

Un conjunto de datos,
reducido a un solo número.

Media, mediana y moda resumen una distribución completa en un valor central. Aprende cuándo usar cada una, cómo se comportan bajo transformaciones, y practica con los mismos casos de clase.

Qué vas a dominar
media (simple, ponderada, agrupada), mediana y moda para datos simples y agrupados, sus propiedades, y la guía de repaso del Control 1.

01 · El mapa mínimo

Tres formas de preguntar "¿dónde está el centro?"

Cada medida responde una pregunta distinta. Elegir la correcta depende del tipo de dato y de qué tan sensible quieres ser a los valores extremos.

Media (μ, x̄)

El punto de equilibrio

Suma todos los valores y divide entre el total. Usa todos los datos, por eso es sensible a valores extremos (outliers).

Mediana (Me)

El valor central

El dato que deja la mitad de las observaciones abajo y la mitad arriba. No le afectan los valores extremos: es robusta.

Moda (Mo)

Lo más frecuente

El valor (o clase) que más se repite. Es la única medida de tendencia central que también sirve para datos cualitativos.

Cuándo usar cada una

Regla práctica

Media: datos cuantitativos sin distorsiones fuertes de valores extremos. Mediana: datos cuantitativos con outliers o distribuciones sesgadas (ingresos, precios). Moda: datos categóricos, o para identificar el valor "típico" en cualquier tipo de dato.

Pista de sesgo

Orden de las tres medidas

En una distribución con cola a la derecha (sesgo positivo, como ingresos o años de estudio): Moda < Mediana < Media. Con cola a la izquierda, el orden se invierte. Si son iguales, la distribución es simétrica.

02 · Media aritmética

Tres fórmulas, una misma idea: repartir el total en partes iguales.

Datos simples, datos ponderados por importancia distinta, y datos agrupados en clases.

Datos simples

Cada dato pesa igual

μ = Σxi / N

Se suman todos los valores y se divide entre el número total de datos.

Media ponderada

Cada dato tiene un peso wi

μ = Σ(wi·xi) / Σwi

Útil cuando cada grupo aporta un número distinto de observaciones (ej. secciones de un curso).

Datos agrupados

El punto medio representa la clase

μ = Σ(fi·PMi) / N

PMi es el punto medio de cada clase; fi es su frecuencia absoluta.

Propiedades de la media: (1) Σ(xi − x̄) = 0. (2) La media de una constante k es la misma constante: k̄ = k. (3) Media de (k·xi) = k·x̄. (4) Media de (xi ± k) = x̄ ± k. Estas propiedades son la base para resolver problemas de "recomposición" de grupos sin recalcular todo desde cero.

Ejercicios de clase · recomposición de grupos

Usa las propiedades, no recalcules desde cero

1. Un grupo de 34 alumnos tiene una media de 8.6. Se incorporan 5 alumnos con media 8.1. ¿Cuál es la media del grupo completo de 39?

Ver solución

μ = (34×8.6 + 5×8.1) / 39 = (292.4 + 40.5) / 39 = 332.9 / 39 ≈ 8.54

2. 15 empleados tienen una edad media de 38.6 años. Este mes, 4 de ellos (edad media 40.75) son promovidos a otro departamento y salen del grupo. ¿Cuál es la nueva edad media de los 11 restantes?

Ver solución

Suma original: 15×38.6 = 579. Suma de quienes salen: 4×40.75 = 163. Suma restante: 579−163 = 416.

μ = 416 / 11 ≈ 37.82 años

3. La sección A (40 alumnos, CUM 7.5) se fusionará con la sección B (20 alumnos). ¿Qué promedio necesita B para que el grupo combinado (60) tenga un promedio ≥ 8.0?

Ver solución

(40×7.5 + 20·xB) / 60 ≥ 8.0 → 300 + 20xB ≥ 480 → xB ≥ 9.0

La sección B necesita un promedio de al menos 9.0.

4. En cambio, A se fusiona con C (CUM 8.6). ¿De cuántos estudiantes debe ser C para que el promedio global sea ≥ 8.0?

Ver solución

300 + 8.6n ≥ 8(40+n) → 0.6n ≥ 20 → n ≥ 33.33

Como n debe ser un número entero de estudiantes, se necesitan al menos 34.

5. Un gimnasio calculó que el peso promedio de sus usuarios en enero 2024 fue 72 kg, pero la báscula sumaba 2 kg de más a todos. La universidad pide el promedio correcto en libras (1 kg = 2.2 libras).

Ver solución

Corrige primero el sesgo (propiedad de la media con una constante): 72 − 2 = 70 kg.

70 kg × 2.2 = 154 libras

03 · Mediana

El valor que parte al conjunto exactamente por la mitad.

No le importa cuánto valen los extremos, solo su posición.

Datos simples, N impar

Un único valor central

Me = x((N+1)/2)
Datos simples, N par

Promedio de los dos centrales

Me = [x(N/2) + x(N/2 + 1)] / 2
Datos agrupados

Se ubica la clase donde "cae" la posición central

Me = Linf(k) + C · [ (N+1)/2 − f.acum(k−1) ] / f(k)

k es la clase donde se encuentra la mediana; Linf(k) su límite inferior; C el ancho de clase; f.acum(k−1) la frecuencia acumulada de la clase anterior; f(k) la frecuencia de la clase mediana.

Mismo caso de clase

Libros leídos por 20 personas

Ordenados: 0×6, 1×5, 2×4, 3×1, 4×2, 5×1, 6×1  (N = 20)

  1. N = 20 es par → promedia las posiciones 10 y 11.
  2. Los seis primeros valores son 0 (posiciones 1–6); los siguientes cinco son 1 (posiciones 7–11). Las posiciones 10 y 11 caen ambas en el valor 1.
  3. Me = (1 + 1) / 2 = 1

La media de este conjunto era 1.75. Si se agrega el dato de una alumna que leyó 7 libros (N=21, impar), ¿qué pasa con la mediana?

Comparación completa: moda = 0, mediana = 1, media = 1.75. El orden Mo < Me < x̄ confirma el sesgo hacia la derecha (unas pocas personas leen muchos libros).

04 · Moda

El único centro que también sirve para categorías.

Para datos no agrupados se obtiene por simple inspección; para datos agrupados hay que ubicar la clase modal.

Datos no agrupados

Por inspección directa

Es el valor que se repite más veces. Puede no existir (todos los valores distintos), o haber más de uno (bimodal, multimodal).

Datos agrupados

Clase modal

Mo = Linf(k) + C · (fk − fk−1) / [(fk − fk−1) + (fk − fk+1)]

k es la clase con mayor frecuencia (la clase modal); fk−1 y fk+1 son las frecuencias de las clases inmediatamente anterior y siguiente.

Mismo caso de clase

Libros leídos por 20 personas

¿Cuál es la moda, y cómo se compara con la media (1.75) y la mediana (1)?

Ejercicio de clase · datos agrupados

Misma tabla de edades, ahora la moda

Edadfi

Media: Σ(fi·PMi) = 11 008.8 → μ = 11 008.8 / 80 = 137.61 libras.

Mediana: (N+1)/2 = 40.5, que cae en la clase 118.8—141.6 (F acum. pasa de 17 a 49). Linf=118.8, C=22.8, f.acum(k−1)=17, fk=32.
Me = 118.8 + 22.8×(40.5−17)/32 = 118.8 + 22.8×0.734 ≈ 135.54 libras.

Moda: la clase modal es 118.8—141.6 (fk=32, la mayor). fk−1=17, fk+1=21.
Mo = 118.8 + 22.8×(32−17)/[(32−17)+(32−21)] = 118.8 + 22.8×15/26 ≈ 131.95 libras.

Media (137.61) > mediana (135.54) > moda (131.95): otra vez un ligero sesgo a la derecha, coherente con que la clase de mayor peso tiene solo 2 bachilleres pero se aleja bastante de las demás.

Control de calidad antes de entregar cualquiera de estas tres medidas: la suma de fi debe dar N; la clase mediana y la clase modal pueden ser distintas (aquí, por casualidad, coinciden); y si el ancho de clase no es constante, la fórmula de la media sigue funcionando igual, pero conviene verificar los puntos medios uno por uno.
